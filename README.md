# FraudShield AI

FraudShield AI is a full-stack fraud detection starter project built with React, Node.js, Express, and MongoDB.

## Project Structure

- `frontend/` - React dashboard and user interface
- `backend/` - Express API, MongoDB models, fraud risk engine
- `docs/` - Hackathon presentation, report, and diagram placeholders

## Quick Start

1. Install dependencies:

```bash
npm run install:all
```

2. Create `backend/.env` from `backend/.env.example`.

3. Start both apps:

```bash
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:5000`
